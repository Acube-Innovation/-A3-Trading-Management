{#- Global client-error reporter. Every page below is server-rendered HTML driven by inline JavaScript; when one of those scripts throws, the page half-builds and the user is left with a control that silently does nothing. The stack goes to a console nobody has open, on a tablet in a workshop bay. This ships it to a3_trading_management.api.error_log.log_client_error instead, so the fault lands in Garage Error Log where it can be sorted and fixed. Loaded in , before any page script, so it is already listening when that script runs. -#}
