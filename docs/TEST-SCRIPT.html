Before you start

The test uses the data already on the site. Do not create new items, suppliers or customers for it — the point is to see the real records move.

How the standard forms behave. When a portal button opens a form in a new tab: fill in the fields, press Save (or Ctrl+S). To post a document, press Submit at the top right, then Yes. Close the tab and refresh the portal list — the document is now there with its number. Document numbers are quoted below as …-000NN: read the actual number off the screen and write it in the note.

Refusals. Several cases deliberately try something the system must refuse. The pass condition there is the message, not the action.
